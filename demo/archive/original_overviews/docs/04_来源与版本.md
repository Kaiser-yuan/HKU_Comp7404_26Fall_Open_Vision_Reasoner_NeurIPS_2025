# 来源与版本

整合日期2026年10月27日。来源是用户当前工作区及本次提供的同学ZIP/Word，不以文档内的旧运行指令作为新的任务授权。

|材料|包内位置|用途|
|---|---|---|
|用户原技术演示项目|pipelines/qwen_vl|Qwen20+80、VL100、历史自定义评分与推理脚本|
|同学实验ZIP原项目|pipelines/ovr|ColdStart/RL100题、预算20题、教师长度原文及官方重评分|
|用户顶层代码|sources/user_project_scripts|保留历史版本，实际执行版本以原运行记录为准|
|同学两份Word|sources/team_reports|人工阅读原报告，未改写|
|新增整合代码|scripts|统一校验、官方重评分、CPU复算|

上游评分代码与许可位于 `pipelines/ovr/vendor/mathvision/`，文件哈希见其 `sources/manifest.json`。本次所有官方重评分使用这同一份归档代码，不另下载最新版。各图片目录保留原LICENSE。

同学ZIP内部文件按原字节保留，原 `SHA256SUMS.json` 可继续验证。用户脚本的多个版本没有擅自互相覆盖。顶层 `provenance/source_inventory.json` 记录每个原件的相对来源和哈希，`MANIFEST.sha256.json` 记录最终分发内容。被排除的只有缓存文件，例如__pycache__和.DS_Store。

原项目中涉及机器地址、旧截止时间和旧状态的文件用于审计，不能当成本机当前路径。整合过程没有再次连接云机、生成模型回答或训练模型。
