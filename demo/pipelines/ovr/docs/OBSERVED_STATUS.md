# 完成范围与解释限制

截至 2026 年 10 月 27 日，两个 OVR 模型在同一固定 100 题上完成 200 次主实验生成；补充 20 题共完成 40 条 16k 轨迹并得到 80 条同轨迹评分视图。已有回答、终止信息、输入、模型身份与官方评分均随包保存。教师长度分析包含固定 1,000 条示范，使用共同 tokenizer。

主实验 ColdStart 34%、RL 31%，不据此证明 RL 固有退化。8k 上限下，两者截断分别为 48% 与 70%。20 题补充中，提高同轨迹预算后 ColdStart 为 20% → 50%，RL 为 30% → 40%，相应截断率为 55% → 0% 与 75% → 20%。该补充不是独立留出集，不能替换原 100 题成绩。

平均推理长度分别为教师 4,444、ColdStart 8,673、RL 至少 10,969 tokens。RL 在学生同题 17/20 对中更长。教师数据的文本任务和原生成条件与学生视觉测试不同，长度差异是描述性观察，不证明能力迁移、实际重新关注图像或更高推理质量。

早期重复输出、模板与部署诊断属于工程历史，不是新的准确率实验。主实验中 7 道题与工程检查有重叠；20 题补充抽样排除这 7 题。人工视觉反思标注、有效步骤与重复比例仍待研究成员复核。本项目没有训练中间 checkpoint，不能推断视觉反思在原始 SFT/RL 的第几训练步出现。

本次仅整理归档与执行 CPU 离线验收，不追加模型生成、训练或付费 API 调用。实际生成记录来自既有运行；命令说明不代表所有历史诊断均需重新执行。
