# Qwen 已测同题 100 题共享包

这批题目与 Qwen 已完成推理的 100 个题目 ID 完全一致，供 OVR-ColdStart、OVR-RL 等模型进行配对比较。图片均为原始字节，没有裁剪或重编码。

## 文件

- questions.jsonl：100 条模型输入，含 id、question、options 和相对图片路径；不含答案。
- answers.jsonl：标准答案、原始解答与题型等信息，仅用于生成后的评分和分析。
- images/：100 张对应原图。
- samples_full.jsonl：完整原始记录，仅供核查，不能将 answer 或 solution 作为推理输入。
- manifest.json：数据版本、全部题目 ID、两阶段抽样规则与原图 SHA256。
- LICENSE：原始数据 MIT 许可。
- QWEN_REFERENCE_SETTINGS.json：Qwen 实际运行参数，供同学对齐。

## 与 Qwen 对齐

- 数据源：MathVision 官方完整 test 划分，而非官方 testmini。
- 原始 20 题固定种子 7404；排除它们后从剩余题目中用种子 740480 再抽 80 题。总计 100 个唯一 ID，没有按模型表现筛题。
- Qwen：BF16、SDPA、do_sample=False、最多生成 4096 tokens。
- 图像处理：min_pixels=200704，max_pixels=1003520；Transformers 4.57.1，原运行使用默认 fast image processor。
- 提示词：去除题目中的 <imageN> 原始标记，传入对应合成原图一次；选项以 A、B、C 等字母排列。要求逐步解答、最终答案写入 boxed，选择题要求选项字母。
- 其他模型应按自身正确的 chat template 加载，记录模板及处理器差异。任何额外 rethinking 提示或长度调整都作为独立实验记录。
- 标准答案必须在生成后读取，不要泄漏到 prompt。
- 保留完整模型输出、题目 ID、token 数、耗时、截断状态和配置。
- 最终对所有模型使用统一评分规则。选择题回答具体选项内容时，需核对是否唯一对应正确选项，不能只做字母比较。

## Qwen 的用户提示词构造

下面是已运行脚本采用的构造逻辑；框架的 chat template 与视觉输入另行处理：

```python
import re

def build_question(row):
    question = re.sub(r'<image\d+>', '', row['question']).strip()
    options = row.get('options', [])
    if options:
        question += '\nOptions:\n' + '\n'.join(
            f'{chr(65+i)}. {text}' for i, text in enumerate(options))
    return question + '\nSolve the problem step by step. Put your final answer in \\boxed{}. ' + (
        'For this multiple-choice question, put only the option letter in the box.'
        if options else 'Put only the final value or expression in the box.')
```

题目与图片路径以解压后的 dataset_test100 文件夹为基准。不得把 100 题子集分数直接当成论文完整基准成绩。
此包不包含模型权重、Hugging Face token、密码或 Qwen 模型回答。
