# 固定20题预算对照

这是2026-10-25准备的探索性补充，原100题实验不改动。

`selection.json`冻结20个题目ID、难度和图像SHA；`references.jsonl`仅用于评分，不进入生成请求。每档4题，seed20261025，排除旧7题工程开发重叠；抽样不读取模型输出或正确率。

ColdStart与RL每题各一次最多16k生成，同时派生8k token前缀，40次生成/80条评分视图。不是80次独立推理；早结束回答在两种预算下完全相同。

运行、统计、断线保护、开关卡及限制见仓库根目录`CLOUD_BUDGET20.md`。准备完成不代表已进行GPU检查或产生了新实验结果。
